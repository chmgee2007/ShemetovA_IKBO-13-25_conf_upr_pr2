## Практическая работа №2 по Конфигурационному управлению

## 1. Общее описание
Инструмент визуализации графа зависимостей для менеджера пакетов npm. 
Программа читает конфигурационный файл, скачивает информацию о зависимостях указанного пакета, строит граф (с учетом транзитивности и ограничения глубины), находит обратные зависимости и генерирует код PlantUML для визуализации.

## 2. Описание всех функций и настроек
Программа настраивается через файл `config.json` в корне проекта:
- `package_name` — Имя анализируемого пакета.
- `repo_url` — URL-адрес репозитория (или путь к файлу в тестовом режиме).
- `test_mode` — Режим работы (true — чтение из локального файла, false — из интернета).
- `version` — Версия пакета.
- `max_depth` — Максимальная глубина анализа зависимостей.
- `filter_substring` — Подстрока для фильтрации пакетов.

## 3. Описание команд для сборки проекта и запуска тестов
- Запуск программы: `python src/main.py`
- Запуск через скрипт: `./run.sh` (для Linux/macOS) или `run.bat` (для Windows).

## 4. Примеры использования
1. Установите зависимости (используется только стандартная библиотека Python).
2. Настройте `config.json` (например, пакет `express`, версия `4.18.2`).
3. Запустите программу: `python src/main.py`.
4. Скопируйте содержимое появившегося файла `graph.puml` на сайт [PlantUML Web Server](https://www.plantuml.com/plantuml/uml/) для получения визуализации.

## 5. Сравнение с штатными инструментами
Штатный инструмент `npm ls express --all` показывает более глубокое дерево зависимостей, так как не имеет ограничения по глубине. Наш инструмент ограничен параметром `max_depth` (по умолчанию 3), поэтому граф выглядит компактнее, что удобно для быстрого анализа.
