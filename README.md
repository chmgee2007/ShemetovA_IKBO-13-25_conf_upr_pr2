# Визуализатор графа зависимостей (Вариант №26)

CLI-инструмент для построения и визуализации графа зависимостей
пакетов PyPI в формате Graphviz DOT / PNG.

## Общее описание
Читает TOML-конфиг, получает прямые зависимости пакета,
строит транзитивный граф итеративным DFS (с ограничением глубины,
фильтрацией и обработкой циклов), умеет выводить обратные
зависимости и рендерить PNG через Graphviz.

## Функции и настройки
| Параметр | Тип | Описание |
|---|---|---|
| package | str | имя анализируемого пакета |
| repo_url | str | URL PyPI или путь к тестовому файлу |
| test_mode | bool | работа с тестовым репозиторием |
| version | str | версия пакета |
| max_depth | int (1..50) | максимальная глубина |
| filter_substring | str | фильтр имён пакетов |
| output_file | str | имя PNG-файла |
